# Project Evidence

The binary photos and screenshots belong in this folder. Use these names to keep the README and assets organized when uploading them:

| File name | Evidence |
|---|---|
| `hardware_setup.jpg` | Full Arduino, breadboard, keypad and sensors |
| `hardware_closeup.jpg` | Arduino board and wiring close-up |
| `python_terminal.png` | Python serial output and update messages |
| `python_code.png` | Python code in VS Code |
| `data_records.png` | Saved access and sensor records |
| `excel_dashboard.png` | Excel dashboard and charts |

Only use the real files from this project. The files are not present in the GitHub folder yet; this note is a naming guide, not a claim that the images have been uploaded.

The project walkthrough link is in [the root README](../README.md) and [docs/project_walkthrough.md](../docs/project_walkthrough.md).
